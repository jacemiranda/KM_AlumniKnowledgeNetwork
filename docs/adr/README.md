# Architecture Decision Records

Store ADRs in this folder.

Use ADRs for revised MVP decisions such as:

- OAuth-only authentication
- feed-first interaction model
- comments replacing private messaging
- voting and authority score logic
- moderation and role-permission boundaries

## File Naming

```text
0001-decision-title.md
0002-decision-title.md
```

## ADR Template

```md
# ADR-0001: Decision Title

## Status

Accepted

## Context

What problem or decision are we addressing?

## Options Considered

- Option 1
- Option 2
- Option 3

## Decision

What did we choose?

## Consequences

- Positive outcome
- Tradeoff or risk
- Follow-up work
```

## Required ADRs

- Database and backend choice
- Authentication and role model
- Deployment approach
- Major implementation decision
