# Standup Notes

Store weekly standup notes in this folder.

Standups should track the revised MVP scope:

- OAuth and first-time setup
- feed, posts, and comments
- search and alumni discovery
- voting, authority, and leaderboard
- moderation, badges, analytics, and release readiness
