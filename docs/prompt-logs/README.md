# Prompt Logs

Each member should keep a prompt log showing how AI assistance was used.

Prompt logs should reflect revised MVP work such as:

- OAuth and profile setup
- feed and comments implementation
- search and alumni discovery
- voting, authority score, and leaderboard
- moderation, badges, analytics, QA, and release documentation

## File Naming

```text
m1-prompt-log.md
m2-prompt-log.md
m3-prompt-log.md
m4-prompt-log.md
m5-prompt-log.md
```

## Minimum Expected Entries

- M1 Project Manager / Scrum Master: planning and coordination prompts.
- M2 Full Stack Developer / Technical Lead: at least 8 meaningful technical entries.
- M3 UX/UI Designer / Front-End Contributor: at least 6 design/frontend entries.
- M4 Knowledge Management Analyst: at least 5 KM/research entries.
- M5 QA & Documentation Lead: at least 5 QA/docs entries.
