# Project Context

## Project Name

Alumni Knowledge Network

## Purpose

Alumni Knowledge Network connects students and alumni through a structured feed-first platform where knowledge is shared publicly, discussed through comments, organized through fields and tags, and recognized through authority score and badges.

## Knowledge Management Foundation

The project uses SECI:

- Socialization: posts and comments create direct knowledge interaction.
- Externalization: practical experience becomes reusable content through posts and discussions.
- Combination: fields, tags, search, and feed structure organize explicit knowledge.
- Internalization: users apply knowledge, gain recognition, and improve through contribution.

## Users

| User | Goal |
|---|---|
| Student | Discover useful alumni knowledge, ask questions, comment, vote, and learn through the feed. |
| Alumni | Share expertise, answer questions, create knowledge posts, and build authority. |
| Moderator | Operationally manage users, posts, comments, fields, badges, and basic analytics. |
| Admin | Maintain full platform control, including moderator management and high-level override authority. |

## Core Modules

- OAuth Authentication
- First-Time Profile Setup
- Universal Feed
- Posts and Comments
- Search
- Alumni / Mentors Page
- Voting and Authority Score
- Leaderboard
- Notifications Modal
- Badges
- User and Content Moderation
- Basic Analytics

## Scope Simplification

The revised MVP intentionally removes:

- private messaging
- conversation threads
- password-based login
- complex community approval workflow
- video calls

Fields and tags now provide the main knowledge-grouping structure.
