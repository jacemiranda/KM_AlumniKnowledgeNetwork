# SECI and Knowledge Structure Context

This file keeps the original path but now documents the revised feed-first knowledge structure rather than the old complex communities workflow.

## SECI Model

The Alumni Knowledge Network uses SECI to explain how alumni knowledge moves through the platform.

| SECI Phase | System Behavior |
|---|---|
| Socialization | Users interact through posts and comments. |
| Externalization | Practical experience becomes reusable written content. |
| Combination | Fields, tags, search, and feed organization connect knowledge. |
| Internalization | Users apply knowledge, build authority, and gain badges. |

## Fields and Tags

The revised MVP simplifies knowledge organization:

- Fields are predefined categories managed by Moderator and Admin.
- Tags are user-defined labels attached to posts.
- Skills are profile-level descriptors used in discovery and search.

This replaces the older heavy community-management concept.

## Alumni Tagging

Users may tag specific alumni in posts when they want relevant expertise or visibility from a known contributor.

## Moderation Context

Moderator and Admin use fields, tags, post type, and comment quality to keep the feed relevant and searchable.
