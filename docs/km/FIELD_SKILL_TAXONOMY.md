# Field and Skill Taxonomy

## Predefined Fields
Fields are admin-managed categories. Users select one field on profile setup.
Posts are tagged with one field.

Suggested initial field list:
- Software Engineering
- Data Science and Analytics
- Cybersecurity
- Network Engineering
- Information Systems
- Game Development
- UI/UX Design
- Project Management
- Business Analysis
- Technical Writing

## Skill Tags
Skills are reusable tags applied to user profiles.
They are not the same as post tags.

Guidelines:
- Skills should be concise (1–4 words): e.g. React, Python, SQL, Agile, Figma
- Skills are searchable via the Search system
- Users add skills during first-time setup and can update via profile management
- Moderators and Admins can add new skills to the global skills list

## Post Tags (User-Defined)
Post tags are created by users when writing a post.
They are not the same as profile skills.

Guidelines:
- Tags should be descriptive and relevant to the post content
- Suggested tag examples: internship, resume-tips, interview, backend, career-shift
- Users are encouraged to reuse existing tags before creating new ones
- Search can surface posts by tag

## Retrieval Rules
- Field filter: narrows feed and leaderboard to a single academic/professional domain
- Skill search: finds alumni by expertise area
- Tag search: finds posts related to a specific topic
- Combined search: name + field + tag + skill can be used together in the search system
