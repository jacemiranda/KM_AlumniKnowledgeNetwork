# Feed Post Structure Rules

## Post Types
Every post must have one of two types:

### Information Post
- Purpose: Share knowledge, insights, experiences, or resources
- Who creates it: Primarily alumni, but students can also post
- Examples: "What I learned from my first year as a software engineer", "Resources for passing the AWS exam"

### Question Post
- Purpose: Ask for advice, clarification, or guidance
- Who creates it: Primarily students, but alumni can also ask
- Examples: "How do I prepare for a technical interview?", "Which field should I choose if I like both data and programming?"

## Required Post Fields
| Field | Notes |
|---|---|
| Title | Clear and descriptive. Sentence case. |
| Content | Main post body. No length limit in MVP. |
| Field | One predefined field selected from the dropdown |
| Post Type | Information or Question |

## Optional Post Fields
| Field | Notes |
|---|---|
| Tags | User-defined. Multiple allowed. |
| Tagged Alumni | Tag one or more alumni relevant to the post topic |

## Alumni Tagging Rules
- Any user can tag an alumni in a post
- Tagged alumni receive a notification
- Tagged posts appear in the alumni's profile under "Posts Tagged In"
- Tagging should be used when the post is directly relevant to the alumni's expertise or experience
- Do not tag alumni as spam or for unrelated content (moderation rule)

## Feed Display Rules
- Default feed shows all posts sorted by most recent
- Users can filter by: Field, Tag, Post Type
- Voting affects visibility through authority score, not direct feed ranking in MVP
